# Product contract

Darzain combines scene planning, editing, generation execution and agent operation around an editable local project. The competitive vision covers art direction, 3D blocking, character continuity, multimodal generation, compositing and filmmaking workflows. These are planned capabilities, not claims about the preview.

The first verified slice uses imported images/audio, shot-intent metadata, the adopted filmmaker timeline and preview, explicit title/audio rendering, project reopening and local agent tools. It has no required cloud cost. User-supplied media and deterministic test fixtures are not AI generation evidence.

MVP acceptance requires recoverable portable projects, persisted cancellable jobs, a real qualified local generation adapter with honest hardware detection, agent parity for editing operations and reproducible production E2E. V1 additionally requires scene composition and camera application, production planning, broader adapters, accessibility, performance budgets, desktop packaging and cross-platform qualification. P00-P09 in ROADMAP defines the dependent release gates.

Do not call the product superior to Higgsfield or Kling without comparative tasks, matching inputs and measured results. No overall completion percentage is published until weighted scope and evidence have been established.
