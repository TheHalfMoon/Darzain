# 0002. Yamakan modular creative foundation

Status: proposed (2026-10-11); pending independent Claude review and founder approval.

## Context
Three pinned donor frontend builds passed but full desktop/provider boundaries were unqualified. The existing bounded reused-module prototype has real editing/export/recovery evidence. New identity/stage tests qualify narrow rules only. The founder now requires a pre-implementation gate.

## Decision
Recommend a small canonical core, adapted editing/scene/production modules, owned FFmpeg, optional isolated inference workers and a shared typed agent surface. Keep one timeline and storage authority. Reject entire-app imports and a second editor/database state engine before approval.

## Consequences
Coherent offline data and agent parity benefit from measured reuse. Migration, render parity, desktop packaging and worker safety still need work. Revisit with a fully qualified challenger. Earlier Darzain ADR remains historical prototype authority. The proposed status follows the founder gate, overriding the ADR skill's usual accepted-status default.
