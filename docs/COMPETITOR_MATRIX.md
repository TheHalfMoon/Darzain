# Competitors and complementary systems

Evidence levels are public product claims, inspected source, bounded build/test qualification and actual application output. They are not interchangeable. No paid competitor account or comparative generation-quality benchmark was run. Product differentiators below are proposed and not claims that Yamakan already exceeds competitors.

| System | Observed strength / evidence | Boundary for Yamakan | Proposed response |
|---|---|---|---|
| Higgsfield | Current public homepage advertises Cinema, Katana editing, Ads Studio and Ad Multiplier; official page snapshot only | Production quality, API entitlement, project portability, offline behavior untested | Compete through editable local project lineage, API parity and reproducible continuity rather than another model picker |
| ArtCraft | Inspected scene/camera/posing and provider source; frontend build succeeds | Native/service/runtime not qualified | Adapt bounded cinematic scene controls to canonical Scene/Camera/Shot |
| AI Video Production Editor | Inspected editing/export/production; 145 donor tests and web build pass | Desktop authority and application-wide state must not be inherited blindly | Reuse bounded editing primitives and replace shell/command ownership |
| Open Generative AI | Broad studio/provider/workflow source; Vite build passes | Full Next/submodule/provider runtime not qualified | Reuse adapter references and coherent discovery, not multiple permanent state engines |
| OpenMontage | Agentic manifests, artifact schemas and gate source; six original gate tests pass | AGPL notice/terms, external tools, durability and full production not qualified | Stage adapter and review artifacts behind Yamakan's jobs/permissions |
| OpenVideoStudio / StoryMind | Identity/character/story pipelines inspected; 22 OpenVideoStudio tests pass with fakes | Test metadata is not proof of identity or rendered continuity | Store versioned character references and benchmark multi-shot likeness with consent |
| InvokeAI / ComfyUI | Canvas/inpaint versus extensible graph generation source | Model environments, global queue/interrupt, custom-code trust, hardware | Optional isolated engines; one project contract and per-engine ownership |
| Kdenlive / MLT / Blender | Mature native timeline/render/3D implementations; selected source inspected | No native build measured here; state/license/distribution differences | Interchange/native worker options with golden export parity before enablement |
| React Video Editor / OpenCut Classic / Remotion | Timeline/composition libraries inspected | Missing engine source, company-size/commercial terms, or unavailable build prerequisite | Challenge initial editing donor only through bounded state/export/cancel experiments |
| Direct model providers / aggregators | Current official API/pricing snapshots | No account, quality, resale or retention qualification | Capability-specific BYOK adapters, hard eligibility filters and receipt-aware budgets |

Quality comparisons must use the same consented assets, shot specification, target format and cost ceiling; retain raw outputs, provider/model revision, seeds where meaningful, prompt, attempts, wall time and charged receipts. Include blind human evaluation for identity, temporal coherence, motion/camera obedience, Arabic text/voice quality and artifact severity. Never infer cross-provider seeds or scores are comparable without a calibrated protocol.

Additional sources complement identified gaps: OpenTimelineIO supplies rational time and editorial interchange without becoming the whole project schema; Mediabunny adds browser demux/mux utilities to evaluate for preview; LangGraph checkpoints inform future durable orchestration without requiring its runtime in MVP; maintained Piper provides an optional local voice candidate with separate GPL/voice-weight qualification.
