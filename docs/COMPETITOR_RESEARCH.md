# Competitor research

Public homepages were scraped through Firecrawl on 2026-10-11 (all HTTP 200). These are vendor claims, not measured runtime behavior. No login, private endpoint or paid generation was used. Exact public URLs and selected evidence are in evidence/competitors.json.

| Product | Public claims observed | Darzain engineering implication |
|---|---|---|
| ArtCraft | Image-to-location, depth compositing, pose controls, mixed assets, local desktop/web and open source | Extract scene state and composition boundaries, qualify actual camera/pose-to-generation behavior |
| Higgsfield | Cinema Studio, camera controls, editing/upscaling, model selection and creative agent workflows | Benchmark controllable shot planning, generation-to-timeline iteration and agent reproducibility |
| Kling | Video generation product surface and model-facing workflows | Investigate public creative controls and task quality; hosted access is optional |

No comparative superiority conclusion is supported. Next study: reproduce an identical 30-second production with traceable scene settings and editable assets, record manual actions, time, failure rate, privacy boundary and output quality. Public feature descriptions must stay distinct from reproduced tests.
