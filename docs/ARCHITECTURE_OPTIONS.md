# Foundation competition

Four strategies were compared using real builds, source boundaries, state compatibility, offline usefulness, test quality and integration cost. No synthetic scores or marketing quality benchmark is presented. Timings are one measured Windows run.

| Strategy | Measured evidence | Immediate value | Integration cost / decision |
|---|---|---|---|
| A — ArtCraft first | Frontend build 138.841 s; scene static REA | Rich 2D/3D/camera source | Native desktop/services unqualified; state translation. Recommend bounded scene donor |
| B — filmmaking editor first | Web build 44.966 s; 145 tests in 4.229 s | Working editing/production primitives | Insecure unrestricted Electron/IPC and credentials boundary. Retain modules, replace shell boundary |
| C — Open Generative AI first | Vite build 24.527 s; provider/Electron REA | Studio/provider breadth | Full Next/submodules/provider runtime unqualified. Retain bounded adapter references |
| D — Yamakan core + adapted modules | Existing reused-module prototype actually exports/reopens, main CI passed | Shared local data/API boundary and offline slice | Requires schema/effects/jobs/desktop expansion. Recommended conditionally |

D retains mature FFmpeg, editing primitives and content storage; it is not greenfield recreation. Main's current API/schema is narrow and not a permanent universal contract without migration.

Editor challengers: React Video Editor delegates to OpenVideo 1.3.1 and its linked engine repository did not resolve; company-size terms and browser export remain gates. OpenCut's pin is a placeholder. OpenCut Classic was not built because Bun was unavailable in the earlier experiment. Kdenlive/MLT are mature native references but Qt/KDE/C++ integration differs from a web module. Revisit with source/rights, offline 30-second export, codec/memory/cancel tests and lossless canonical-state mapping.

OpenMontage can provide production manifests, stage rules/artifact schemas and knowledge through a scoped adapter. Its checkpoint rules are not a durable GPU supervisor. Composer source imports Google Fonts and an asset resolver; offline fonts, bounded assets and arbitrary-code isolation need qualification. Do not install its shell tools/skills as unrestricted agent authority. AGPL provenance remains explicit.
