# Release gates

Current designation: engineering preview 0.1.0; no public release or installer qualification.

The preview may merge only after meaningful local tests/build/lint/provenance, review of material boundaries, no unresolved critical defects and CI on the exact PR head. The first empty-repository bootstrap is administrative documentation only. Main must be verified after a normal merge commit.

MVP additionally needs recoverable portable projects, durable jobs, a real local generation workflow, full creative tool parity and documented hardware limitations. V1 needs scene composition, production planning, representative performance, process isolation, supported-platform packages, accessibility and release-grade E2E. Required source/model licenses and notices must accompany distributable artifacts.

No paid service, founder-funded server or provider account is required for local editing/export. Optional generation services require explicit configuration and truthful cost descriptions. Bundled fonts, weights and binaries need separate terms and are not included in this preview.

Do not infer production readiness from a successful build, a copied source tree, one PR or an attractive screenshot.
